# Pricing Guide

## Plan Comparison

### Free Plan - $0/month
**Best for**: Individual developers and small projects

- 100 API calls per month
- Basic support (48-hour response time)
- 1 user seat
- Community forum access
- Standard API rate limits
- 7-day data retention

### Premium Plan - $99/month
**Best for**: Growing teams and production applications

- 10,000 API calls per month
- Priority support (24-hour response time)
- 5 user seats
- Advanced analytics dashboard
- Higher API rate limits (100 req/min)
- 90-day data retention
- Webhook integrations
- Custom domains

### Enterprise Plan - Custom Pricing
**Best for**: Large organizations with specific requirements

- Unlimited API calls
- Dedicated support (4-hour response time)
- Unlimited user seats
- Custom integrations
- SLA guarantees (99.9% uptime)
- Unlimited data retention
- SSO/SAML authentication
- Dedicated account manager
- On-premise deployment options
- Custom contracts and invoicing

## Add-Ons (Available on Premium+)

| Add-On | Price | Description |
|--------|-------|-------------|
| Extra API calls | $10/1,000 | Additional API call bundles |
| Additional users | $15/user/month | Beyond plan limits |
| Extended retention | $25/month | 1-year data retention |
| Priority queue | $50/month | Faster API response times |

## Billing Details

- **Billing Cycle**: Monthly or annual (2 months free with annual)
- **Payment Methods**: Credit card, wire transfer (Enterprise only)
- **Currency**: USD (EUR and GBP available for Enterprise)
- **Invoices**: Available in dashboard under Billing section

## Upgrading and Downgrading

- **Upgrades**: Immediate, prorated billing for remainder of cycle
- **Downgrades**: Take effect at next billing cycle
- **Plan Changes**: Unlimited, no fees

## Volume Discounts

Contact sales for volume pricing on:
- 50,000+ API calls/month
- 25+ user seats
- Multi-year commitments
