# Escalation Criteria

## When to Escalate to Human Support

This document defines when automated support should hand off to human agents.

## Immediate Escalation (HIGH Priority)

These issues require immediate human attention:

### Security Issues
- Suspected account compromise
- Unauthorized access reports
- Data breach concerns
- Suspicious activity alerts

### Service Outages
- Complete inability to access service
- Widespread API failures
- Data loss or corruption reports

### Financial Impact
- Billing errors over $100
- Disputed charges
- Fraudulent transaction reports
- Contract or invoice disputes

### Legal/Compliance
- GDPR data requests
- Legal document requests
- Subpoenas or legal notices
- Compliance audit requests

## Standard Escalation (MEDIUM Priority)

These issues should be escalated but are not urgent:

### Complex Technical Issues
- Bugs that can't be reproduced
- Integration failures after troubleshooting
- Performance issues specific to one account
- Custom configuration problems

### Billing Issues
- Refunds between $50-$100
- Subscription modification requests
- Payment method issues after self-service fails
- Plan migration questions

### Account Issues
- Account recovery after failed self-service
- Permission or access problems
- Team management issues
- SSO/SAML configuration

## Low Priority Escalation

These can be queued for batch processing:

### Feature Requests
- New feature suggestions
- Integration requests
- API enhancement ideas

### General Feedback
- Product feedback
- Service improvement suggestions
- Documentation corrections

## Escalation Process

1. **Gather Information**
   - Customer email and account ID
   - Detailed issue description
   - Steps already attempted
   - Error messages or screenshots

2. **Set Priority**
   - HIGH: Security, outages, major financial impact
   - MEDIUM: Complex issues, moderate billing
   - LOW: Requests, feedback

3. **Create Ticket**
   - Include all gathered information
   - Set appropriate priority
   - Assign to correct queue

4. **Communicate SLA**
   - HIGH: 4-hour response
   - MEDIUM: 24-hour response
   - LOW: 48-hour response

## Do NOT Escalate

These should be handled by automated support:
- Password resets
- Basic usage questions
- Documentation clarifications
- Simple refunds under $50
- Standard plan comparisons
- Feature availability questions
